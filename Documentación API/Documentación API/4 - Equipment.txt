Add device fence
Example of a request to create a circular fence based on latitude and longitude:
{
    "triggerType":1,
    "imei":"868120162158934",
    "mapType":1,
    "oneTime":1,
    "setting":"101.857706 22.575529 368",
    "type":2,
    "fenceName":"8934的围栏"
}
Example of creating a circular fence request based on a Chinese address

{
    "createByAddress": 1,
    "triggerType":1,
    "imei":"868120162158934",
    "cityId": 310113,
    "address": "蕰川路1999号",
    "radius": 100,
    "oneTime":1,
    "fenceName":"8934的围栏"
}
Example of creating an area fence request
{
    "triggerType":1,
    "imei":"868120162158934",
    "type": 1,
    "oneTime":1,
    "fenceName":"8934的围栏",
    "setting": "310000"
}
Create polygonal fence request example
{
    "triggerType": 1,
    "imei": "867597017868891",
    "mapType": "1",
    "oneTime": 1,
    "setting": "120.52156152553987 30.69047320037628,120.5289276311816 30.68761608261841,120.52271135666444 30.68510050606933,120.52156152553987 30.69047320037628",
    "type": 3,
    "fenceName": "424242"
}
Example of fortified fence request
{
    "imei": "860419050024984",
    "triggerType": 2,
    "mapType": 1,
    "oneTime": 0,
    "type": 2,
    "setting": "121.436079 31.388727 1000",

    "cycle": "1111100",
    "time": "08:00-20:59"
}
Request Body schema: application/json
triggerType	
integer
1 will alarm when entering the fence, 2 will alarm when exiting the fence, and 3 will alarm when entering and exiting the fence.

mapType	
integer
Coordinate system (1: bd09ll, 2: gcj02ll, null: wgs84ll)

oneTime	
integer
Whether to use it only once 1 yes once 0 no multiple times

type	
integer
fenceName	
string
fence name

imei	
string
Device No

createByAddress	
integer
Default: "0"
Whether to create based on address (currently only circular fences are supported) 1: Yes, others: No

setting	
string
Required when "createByAddress" is not equal to 1, "101.857706 22.575529 368" Circular fence: "Latitude and longitude radius (meters)", Regional fence: "cityId" Polygon fence: 120.52156152553987 30.69047320037628,120.5289276311816 3 0.68761608261841,120.52271135666444 30.68510050606933

cityId	
integer
Required when "createByAddress" is equal to 1, national standard region ID

address	
string
Required when "createByAddress" is equal to 1, detailed address (street, house number)

radius	
integer
Required when "createByAddress" is equal to 1, circular fence radius (meters)

fortifyType	
integer
Defense type, 1: Temporary defense, 2: Customized defense

cycle	
string
Period, 7 digits from left to right represent Monday to Sunday respectively, 0: off, 1: on

time	
string
Defense time, the format of daily time period is 00:00-23:59

startTime	
integer
Start time, timestamp, unit seconds

endTime	
integer
End time, timestamp, unit seconds

successful operation
