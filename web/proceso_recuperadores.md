En consultar placa, es necesario que al generar pago o recuperar moto pase lo siguiente:

en generar pago que tambien se pueda poner la opcion de metodo de pago: Efectivo, nequi, Transferencia 
tambien que se pueda poner si el pago fue presencial o remoto.

si el pago se selecciona presencial el recuperador debe tomar una foto, esta foto se guardara en el bucket fotos/placas_recuperadas
y en la tabla recuperadores. 

la foto tambien se debe de ver la card que se manda a whatsapp. quiero que ese proceso sea procedural para que asi no sea confuso para los recuperadores que son personas con bajo nivel educativo, entonces quiero que el proceso no tengs una gran carga cognitiva. manten la ui.

esta es la tabla recuperadores 

create table public.recuperadores (
  id bigint generated by default as identity not null,
  nombre_recuperador text null,
  fecha_hora_asignada timestamp without time zone null,
  placa_asignada text null,
  estado_moto text null,
  "Pagado" bigint null,
  multa bigint null,
  fecha_hora_recuperada timestamp without time zone null,
  fecha_hora_abono timestamp without time zone null,
  foto text null,
  tipo_pago text null,
  presencial boolean null,
  gps_ubicacion text null,
  constraint recuperadores_pkey primary key (id)
) TABLESPACE pg_default;
